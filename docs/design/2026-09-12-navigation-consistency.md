# 栏目名称与浏览路径统一

分支 codex/knowledge-navigation，未合并或推送。

- 浏览器栏目标题统一知识、思考、资源；页脚分别提供项目、知识、思考、资源、关于。
- 相关内容标签统一思考、项目、资源，保留正文中有具体含义的“工具”“笔记”等词。
- 旧资料架 /library 与 /library-resources 接入资源外部资料分类，保留 q 搜索词；旧 type 参数不再单列，统一使用外部资料分类。
- 旧知识入口 /learning?kind=CONCEPT 和无 kind 的旧列表入口统一 /topics。思考、详情、审核入口保留。
- 知识和资源详情支持返回来源目录，恢复分类、关键词和保存的滚动位置；思考保持现有返回功能。
- 关于两个子页仍有独立内容，保留深链接，在关于首页添加建站缘由、当前方向两个次级入口。

验证：88 个源文件语法检查通过，94 项测试通过。浏览器验证资料架旧链接带 MCP 搜索进入资源分类、清单详情返回保留分类、MCP 术语返回保留关键词。滚动恢复已实现，未完整覆盖所有内容长度下的设备场景。
