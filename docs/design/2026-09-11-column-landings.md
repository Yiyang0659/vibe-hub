# 项目、知识、思考、关于栏目还原

范围：四张 2026-09-11 提供的参考图对应的栏目页。首页和已确认的六项导航保持原样；详情页不在此次调整范围。

## 交付
- 项目：左右介绍与指标、三张项目卡、参考插画、记录方法横条。
- 知识：搜索与分类、六项知识预览、两项系列规划、内容说明侧栏。已发布知识链接原详情；缺少正文的条目展示明确的整理中预览。全部知识入口保留原完整索引。
- 思考：横向精选卡、栏目说明、五张最近思考卡、搜索与分类。参考选题尚无正文，明确标记整理中；已有学习记录入口可访问原内容。
- 关于：个人介绍、当前关注、三张说明卡、真实 GitHub 与站内知识入口。没有填入参考图中的示例邮箱或 Notion 链接。

## 规范与资源
统一使用原 `site-container` 的 1216px 上限、响应式边距及共享字体 token。样式在 `src/features/columns/columns.css`，仅针对新栏目页。针对栏目页取消旧 main 顶部 padding 叠加，改用参考图简短页尾；首页与其他页不受影响。

小插画以 CSS 显示用户参考图的局部，原图保存在 `assets/columns/`，不以整张截图代替页面。后续有透明原始插画时可替换。关于页沿用现有角色素材。

## 验证
71 个 JS 文件语法检查；72 项自动测试通过。浏览器 1435×983 与 390×844 核对四页，无横向溢出；知识搜索、分类和思考预览开关已验证。截图存于 output/playwright/columns-*.png。
