## 当前应从这里继续

用户认可首页前两屏的方向，当前先固定它们共用的宽度、边距、字号与按钮规范。项目页、文章页、后续首页区块仍可继续定制，不要把现有内页布局当成最终模板。

## 已实现

1. 首屏保留原来的核心文案、左右布局、人物互动、两张方法说明卡。
2. “查看项目”和“读最近文章”移到三张独立统计卡上方；统计卡没有合并。
3. AI Learning OS 卡片不跳转，移除 View Case Study 按钮。
4. 状态标签下加入浅灰蓝“想与做的书桌”铭牌，配笔记本与铅笔线稿；文案为“把问题摆上桌，把想法一点点做出来。”；宽度随内容收缩。
5. 第二屏替换为左侧自述、关于入口及背向学习插画，右侧“这里记录了什么”及文章、项目、工具三条整行链接。
6. 新插画保存于 assets/hero/learning-desk.png。浅色主题融合白底，深色主题保留白色画幅。
7. 首页所有分区容器最大1216px，首屏、第二屏与项目展示区边界对齐；统一响应式边距及标题、正文层级。
8. 导航点击范围与主次按钮尺寸统一，滚动不再改变导航宽度。保留菜单、原有路由和选中态。
9. 公共规则集中在 src/styles/home-foundations.css，当前规范记录在 docs/design/home-foundations.md。
