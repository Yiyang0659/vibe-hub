# 首页第三至第五屏

依据用户直接提供的五张首页原图：第一、第二屏保持现状，第三至第五屏参考图 3、4、5。附件的全站说明作为参考，本次未扩大到其他栏目重构，也未用其 1280–1360px 建议替换已确认的 1216px 基线。

## 本次实现

- 第三屏：左侧标题、介绍和入口；右侧知识搜索、分类、四条预览、实践专题。
- 第四屏：左侧介绍及引用卡；右侧精选思考、最近记录及类型筛选。
- 第五屏：左侧介绍和入口；右侧资源分类、最多六条预览及真实分类数量。
- 组件统一使用原首页颜色与字体变量，外层沿用 zh-container，样式限定在 hp-* 类。
- 手机改为单列，中等宽度减少卡片列数；没有固定高度或缩放整个页面。

## 数据与素材

现有公开内容驱动列表。专题、文章数量不足参考图时不补造；资源不标记未经确认的“我在用”。来源标题混有 VibeHub/MDN 的旧条目未放入首页精选，原数据保留。精选思考用程序绘制的笔记本装饰替代图中的摄影素材，未把整张效果图当成网页背景。

入口暂接现有可用的 learning、notes、toolbox、library 路由。首页前两屏和导航不改动，后续栏目定制再同步导航命名及统一资源入口。

68 项测试通过，包含分类和搜索组合、空结果、重置、草稿排除、前三个预览区顺序与已有首屏人物交互。68 个源码文件语法检查通过，本地服务 HTTP 200。未进行浏览器视觉验收；以本地实际预览供用户核对。
