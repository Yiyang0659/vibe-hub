# 学习航海日志设计说明

## 产品定位

这是一个面向个人长期使用的中文学习知识库。它借鉴 VibeHub 的“分类目录—知识详情—即时练习”信息结构，但不复刻其品牌、文案或页面视觉。网站围绕“航海日志”组织学习过程：知识主题是航线，章节是海域，完成记录是航迹，收藏内容是灯塔。

首版的成功标准是：访客能在一分钟内找到一个主题、理解内容、完成一道练习，并在刷新页面后保留收藏、完成状态和个人笔记。

## 信息架构

- 首页：学习概况、继续学习、主题航线、近期条目和今日练习。
- 知识库：按前端、后端、AI 协作、产品设计、工程实践分类浏览，支持全文搜索和难度筛选。
- 详情页：一句话定义、为什么重要、核心要点、实践示例、常见误区、行动清单、延伸方向、个人笔记和完成按钮。
- 练习舱：从知识条目抽取选择题，提交后即时解释，并更新练习统计。
- 收藏夹：汇总用户标记的重要知识点。

所有首版数据保存在浏览器 localStorage。读取失败时应用回退到空状态；页面按钮始终提供文字标签和清晰焦点状态。

## 视觉与交互

视觉方向是“现代航海日志”，不是复古道具陈列。底色使用温暖纸张色，正文使用深墨色，朱砂红作为主操作和标记色，海松绿承担分类和进度信息。标题采用有书卷感的中文衬线字体，正文采用易读的中文黑体。地图网格、经纬线、航线和印章只作为低对比度背景细节。

桌面端采用左侧固定航海仪表盘、右侧内容流；移动端改为顶部导航和底部快捷栏。页面切换有短促淡入，卡片悬停只使用轻微位移，尊重 reduced-motion。搜索支持 `/` 快捷键和清空，条目卡可收藏，详情页可保存笔记并标记学完，练习提交后展示解释。

## 验收策略

- 使用 Node 内置测试验证搜索、筛选和进度统计等纯逻辑。
- 使用语法检查保证脚本可解析。
- 在本地浏览器检查桌面和移动视口，覆盖首页、知识库、详情页、练习和无结果状态。
- 检查键盘焦点、颜色对比、按钮标签和 reduced-motion。
