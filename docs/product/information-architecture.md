# 信息架构

## 对外主导航

```text
首页
├── 项目
├── 学习
├── 工具
└── 关于
```

主导航保持精简，呈现个人方向、学习过程、实践和可复用工具。学习栏目聚合知识、笔记、专题与成长记录。

## 扩展知识入口

```text
学习入口
├── 知识条目与学习笔记
├── 专题与成长记录
├── 阅读
└── 资料架

个人工具入口
├── 全局搜索
├── 已保存
├── 练习
└── 个人工作台
```

## 内容关系

内容实体通过稳定 ID 建立关联：术语帮助解释文章和项目，文章记录理解过程，项目提供实践证据，工具承接可复用方法。关联只保存 ID，不把其他实体的正文复制进当前对象。

主要 URL：

| 栏目 | 地址 |
| --- | --- |
| 首页 | `#/home` |
| 项目 | `#/work`、`#/work/:id` |
| 学习 | `#/learning`；旧 `#/notes` 入口继续兼容 |
| 笔记与成长记录 | `#/notes/:id` |
| 术语 | `#/topics`、`#/topics/:id` |
| 阅读 | `#/reading`、`#/reading/:id` |
| 工具 | `#/toolbox`、`#/toolbox/:id` |
| 资料 | `#/library` |
| 工作台 | `#/workspace` |
| 已保存 | `#/saved` |
| 关于 | `#/about` |

学习列表支持 q、category、kind、collection 查询参数；专题引用现有条目，尚未实现课程章节与进度。原有待核实内容保留在历史入口，草稿不进入公开展示（静态资源不构成访问控制）。
