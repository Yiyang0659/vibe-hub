# 用户流程

## 访客了解作者

```text
打开首页 → 阅读个人定位 → 查看重点项目 → 阅读相关思考 → 打开可复用工具
```

## 按问题寻找内容

```text
打开全局搜索 → 输入中文、英文或问题 → 按内容类型查看结果 → 进入详情 → 沿关联路径继续浏览
```

## 学习一个术语

```text
术语索引 → 筛选或搜索 → 阅读定义和例子 → 完成快速检查 → 记录个人笔记 → 标记完成
```

## 保存和回访

```text
内容详情 → 点击收藏 → 已保存页面 → 再次打开对应内容
```

## 快速记录

```text
打开个人工作台 → 输入项目进展和材料 → 生成结构化摘要 → 保存为记录／文章／工具草稿
```
