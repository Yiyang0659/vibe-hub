# 个人学习闭环 MVP 设计

## 目标

把当前以术语浏览和练习为主的本地网站，扩展成可以持续记录真实项目问题、关联知识、追踪掌握程度并安全备份的个人学习工作台。

第一版必须形成一条完整闭环：遇到问题时快速记录，解决后整理为项目案例并关联术语，之后可通过搜索、首页最近记录和复习状态重新找到它。

## 当前基础

项目使用原生 HTML、CSS、ES Modules、Hash 路由、`localStorage` 和 Node 内置测试。现有 60 个术语已经具备分类、定义、示例、误区、行动清单、关联术语和选择题；用户状态包含收藏、完成、单条术语笔记、最后访问条目和练习总分。

第一版继续使用现有技术栈，不引入框架、服务端、账号系统或数据库依赖。

## 第一版范围

### 1. 真实最近访问

- 打开术语详情时记录 `visitedAt`，每个术语保留最近访问时间和累计访问次数。
- 首页“最近访问的模块”按真实访问时间倒序显示，未产生访问历史时才回退到推荐术语。
- 首页继续学习优先选择最近访问但尚未掌握的术语。

### 2. 统一搜索

- 全局搜索同时检索术语、术语笔记和项目问题记录。
- 搜索结果必须显示类型标签：`术语`、`笔记` 或 `项目问题`。
- 点击术语和笔记结果进入对应术语详情；点击项目问题进入项目日志并定位该记录。
- 搜索数据全部来自当前浏览器，不发送到网络。

### 3. 快速记录与项目问题日志

- 新增 `#/capture` 快速记录页，最少只需标题即可保存到收件箱。
- 快速记录字段包括标题、项目、现象或报错、上下文和关联术语。
- 新增 `#/projects` 项目日志页，展示全部记录，并可按 `待整理`、`处理中`、`已解决` 筛选。
- 项目记录可继续补充尝试过程、根因、解决方法、验证证据和可复用规律。
- 每条记录保留创建时间与最后更新时间。
- 项目日志中的关联术语可以跳转到术语详情；术语详情反向展示关联的项目记录。

### 4. 结构化学习状态

- 术语状态由二元“完成/未完成”升级为 `未接触`、`正在理解`、`已实践`、`可以复述` 四级。
- 现有 `completed` 数据迁移为 `可以复述`，其余默认 `未接触`。
- 术语详情允许修改状态与 1–5 级信心值。
- 保存状态时记录最近复习时间和复习次数。
- 首页进度以 `可以复述` 数量计算，同时展示 `正在理解` 和 `已实践` 数量。

### 5. 数据导入导出

- 设置入口放在项目日志页顶部，支持下载包含所有用户数据的 JSON 备份。
- 支持从同格式 JSON 恢复数据；导入前校验版本和必要字段。
- 导入操作采用整包替换，但必须在页面中明确提示会覆盖当前本地记录，并要求用户再次确认。
- 静态术语内容不写入备份，只备份用户状态、笔记、访问历史和项目记录。

### 6. 深色与白色主题

- 当前深色开发实验室主题保持为默认值。
- 新增白色主题，复用同一套布局和组件，仅通过 CSS 变量切换背景、文字、边框、强调色与阴影。
- 主题切换按钮位于网页顶栏右上角，显示“深色”和“白色”两个状态，支持键盘操作并提供 `aria-pressed`。
- 用户选择持久化到本地，刷新后保持。
- 两种主题都必须保证正文、按钮、输入框、卡片、弹窗和状态色有足够对比度。

## 页面与导航

- 侧栏增加“项目日志”入口。
- 首页主要行动区增加“快速记录”按钮。
- 移动端底栏保持四个主要入口：控制台、知识库、测试、记录；收藏列表移动到知识库页面的筛选入口中，原收藏路由继续兼容。
- 顶栏右侧依次显示日期、本地数据状态和主题切换。
- 快速记录成功后进入项目日志并高亮刚创建的记录。

## 数据模型

用户数据升级为 `learning-workspace-state-v2`：

```js
{
  version: 2,
  favorites: [],
  notes: {
    [lessonId]: {
      content: '',
      updatedAt: ''
    }
  },
  learningRecords: {
    [lessonId]: {
      status: 'unseen' | 'learning' | 'applied' | 'articulated',
      confidence: 1 | 2 | 3 | 4 | 5,
      firstSeenAt: '',
      lastReviewedAt: '',
      reviewCount: 0,
      visitCount: 0,
      lastVisitedAt: ''
    }
  },
  projectIssues: [
    {
      id: '',
      title: '',
      project: '',
      symptom: '',
      context: '',
      attempts: '',
      rootCause: '',
      solution: '',
      verification: '',
      reusableRule: '',
      relatedLessonIds: [],
      status: 'inbox' | 'working' | 'resolved',
      createdAt: '',
      updatedAt: ''
    }
  ],
  practice: {
    answered: 0,
    correct: 0
  },
  theme: 'dark' | 'light',
  motionMode: 'trace' | 'scan' | 'packet'
}
```

应用启动时执行一次幂等迁移：读取旧的 `learning-voyage-state-v1`，将旧笔记字符串转为带更新时间的对象，将 `completed` 转为 `articulated`，将分散的练习统计转为 `practice` 对象，并保留收藏和动效设置。旧版 `day`、`night` 或缺失的主题值都映射为新版默认 `dark`，避免升级后视觉发生意外变化。迁移成功后写入 v2，但不主动删除旧键，便于回退。

## 模块边界

- `js/data.js` 和 `js/expanded-data.js`：只负责静态术语内容。
- 新增 `js/state.js`：默认状态、迁移、读取、保存、导入校验和导出序列化。
- 新增 `js/knowledge.js`：最近访问、统一搜索、学习统计、项目与术语关联等纯逻辑。
- `js/app.js`：路由和页面渲染，不直接处理迁移或搜索算法。
- `styles.css`：在现有变量基础上增加白色主题和新增页面样式。

## 失败与空状态

- 存储数据损坏时使用默认状态，并显示非阻塞提示。
- 搜索无结果时显示当前关键词和可执行的清空操作。
- 项目日志为空时提供“快速记录第一个问题”入口。
- 导入文件格式错误时不修改现有数据，并显示具体原因。
- 术语被移除或关联 ID 无效时忽略无效关联，不阻断页面渲染。

## 测试与验收

### 自动化测试

- v1 到 v2 数据迁移保持收藏、笔记、完成状态和练习统计。
- 最近访问按时间倒序、去重并正确回退。
- 统一搜索可找到术语定义、个人笔记、项目标题和报错文本。
- 项目状态筛选和术语反向关联正确。
- 导入校验拒绝错误版本和缺失必要结构的数据。
- 学习统计只把 `articulated` 计入完成进度。

### 浏览器验收

- 首页、知识库、术语详情、练习、快速记录和项目日志均可正常导航。
- 创建一条问题记录后，可在项目日志、全局搜索和关联术语详情中找到。
- 修改术语状态后，首页统计和详情状态同步更新。
- 深色与白色主题按钮位于右上角，刷新后保持选择。
- 360px、820px 和 1280px 视口无横向溢出。
- 两种主题下均检查首页、术语卡、项目表单、搜索弹窗和练习反馈。

## 暂不实现

- 账号、云同步和多人协作。
- 自动调用 AI 生成笔记、标签或题目。
- 图片、视频和任意文件上传。
- 可拖拽的可视化知识图谱。
- 复杂间隔重复算法；第一版只记录复习时间和次数。
- 批量扩充术语数量或为全部术语制作互动图解。
