# 产品需求

## 核心体验

访问者应能从首页快速理解作者关注的方向，并在项目、文章和工具之间顺畅浏览。需要深入学习时，可以进入术语、阅读和资料栏目；个人使用时，可以通过搜索、收藏和工作台重新找到内容。

## 功能要求

1. 首页展示个人定位、重点项目、近期文章、常用工具和知识入口。
2. 项目、文章、术语、阅读、工具与资料均有稳定 ID 和可复制的 Hash URL。
3. 全局搜索覆盖全部内容实体，并按类型展示结果。
4. 术语支持完成状态、个人笔记、关联内容和快速练习。
5. 收藏、主题、学习进度和个人记录持久保存在本地浏览器。
6. 旧路由 alias 继续可访问，不因文件整理导致链接失效。
7. 桌面端与移动端均能使用主要导航和核心交互。

## 非目标

- 登录注册、云同步和权限系统。
- 在线富文本内容管理后台。
- 依赖前端框架或构建服务才能运行。
