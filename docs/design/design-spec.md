# 设计规范

## 视觉基调

网站使用克制、温暖的编辑部风格：内容优先，项目和文章形成主要叙事，技术细节通过等宽字体和轻量标签表达。日间与夜间主题共享同一套语义变量。

## 权威样式入口

- `src/styles/index.css`：浏览器唯一加载入口。
- `src/styles/tokens.css`：颜色、字体、字号、间距、圆角与动画时间。
- `src/styles/base.css`：基础排版和通用元素。
- `src/styles/layout.css`：应用外壳、通用页面布局和详情页骨架。
- `src/features/home/home.css`：首页专属样式。
- `src/styles/index-pages.css`：多个栏目共用的索引页骨架。
- `src/styles/detail-pages.css`：多个栏目共用的详情页排版。
- `src/features/<栏目>/*.css`：首页、文章、术语和工作台等栏目专属样式。
- `src/shared/components/*.css`：跨栏目组件样式。

## 修改原则

1. 优先调整 token，不在页面中重复定义相同颜色和间距。
2. 栏目专属选择器以栏目根类名限定范围，避免影响其他页面。
3. 共享视觉模式只有在两个以上栏目使用时才进入公共样式。
4. 保留键盘焦点、减少动态效果偏好和移动端断点。
5. 文件迁移与视觉改版分开进行，避免无法判断回归来源。
