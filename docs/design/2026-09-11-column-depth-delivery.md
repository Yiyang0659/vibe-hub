# 栏目连续浏览交付

本轮将栏目主页从概览延伸为连续浏览页面，沿用现有网格背景、容器宽度、导航和字体。未修改首页第一、第二屏。

## 页面

- 知识：`#/learning?kind=CONCEPT`。精简概览，按产品、AI、Agent、开发展示已有知识，展开两个系列的章节，再连接实践与全部知识。
- 项目：`#/projects`。保留概览，逐项展开三个项目的问题、方案、结构示意、模块和下一步。新增“向下了解项目”页内定位。
- 思考：`#/learning?kind=NOTE`。精选与选题之后展示真实发布记录，再按主题组织草稿；不虚构阅读数或发布时间。
- 资源：`#/toolbox`。整合当前工具与外部资料；按场景展开，单项工具和清单展示使用路径。工具进入原详情，资料访问安全外链。
- 关于：`#/about`。补充学习、实践、整理的叙事，以及当前方向和完整故事入口。

## 内容与交互

- 知识、思考、资源搜索覆盖完整栏目目录，不局限于首屏。
- 搜索支持关键词与分类组合，显示结果数、空结果、清除筛选；条件保存在 URL，刷新与返回后恢复。
- 知识主题分类与完整索引共用分类函数。
- 发布状态过滤继续使用既有规则；编辑草稿明确标注，项目设计开发状态保留。
- 新增样式限定在栏目组件，不引入新的视觉系统。

- `npm test`：81 项通过（增加完整目录检索、发布状态、分类一致性、外链安全和项目阶段检查）。
- 浏览器检查 5 个栏目 × 390 / 1435 px：均无页面级横向溢出。
- 验证搜索命中、空结果、清除、刷新恢复、Agent 分类，以及项目页内定位；浏览器控制台无错误。
