## 5. 明确“记录学习和沉淀过程”的定位

**用户**

目前没有很多项目或成熟文章，更多是小插件、术语和自己的总结。网站的核心应该是记录学习、理解、实践和沉淀的过程，同时保留个人网站展示属性。

**讨论结果**

网站定位调整为“个人展示入口 + 持续生长的学习系统”。首页继续表达个人方向，内容区优先展示最近学习、正在实践、工具方法和成长记录；项目案例和完整文章随着真实积累再逐步增加。

参考文件：[个人展示与学习记录整合方案](../../design/2026-09-10-personal-learning-site-proposal.md)

## 8. 再次梳理长期栏目

**用户**

重新提出五类长期内容：

1. 项目：阶段、成果、复盘和问题。
2. 学习知识：术语、AI 与产品知识、系列、学习文章和网站。
3. 自己的沉淀：笔记、思考、文章、产品拆解和竞品分析。
4. 工具与收藏：自己的小工具，以及外部 Prompt、Skills、插件、网站和有趣资料。
5. 关于：简单介绍自己、正在做的事和建站原因。

用户同时提供了一份 AI 分析，要求结合当前项目客观判断，不能直接照搬。

**分析结论**

建议长期栏目采用“首页 / 项目 / 知识 / 思考 / 资源 / 关于”，但修正原分析中过于绝对的边界：

- 知识和思考不按客观、主观二分，而按内容主要用途区分。
- 项目允许小型、进行中、暂停或结果不理想的真实实验。
- 系列是一种组织方式，可以串联知识、笔记和项目实践。
- 工具、Skill、Prompt 是类型；开源是属性；原创、外部和改编是来源。
- 同一内容只有一个主要正文，其他栏目通过关联入口引用，避免重复维护。

具体示例：解释 Agent 原理归知识；记录第一次搭建 Agent 的判断归思考；展示自己做的 Agent 归项目；推荐外部框架并附使用入口归资源。

参考文件：[栏目与长期内容规划再次评估](../../research/2026-09-10-content-columns-reassessment.md)
