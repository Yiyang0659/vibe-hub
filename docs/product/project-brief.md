# 项目简介

## 项目定位

“想与做”是一个记录 AI 学习与实践的个人网站。保留个人首页的表达，围绕术语理解、学习笔记、小实验和工具记录持续积累的过程。当前优先支持记录、整理与回看，项目案例和成体系的文章随实践逐渐增加。

## 目标读者

- 想了解作者做过什么的合作方或招聘方。
- 对 AI 产品、Agent 和应用工程感兴趣的产品与开发人员。
- 未来需要重新找到某个概念、项目经验或方法的作者本人。

## 核心内容

- 项目：真实做过或验证过的产品、原型与实验。
- 文章：从项目和研究中形成的判断与思考。
- 术语：用产品和实践视角解释关键概念。
- 工具：可以直接复用的 Prompt、Workflow、Checklist 和 Template。
- 阅读与资料：影响过实践判断、值得再次打开的外部内容。

## 当前边界

网站是纯静态应用，个人收藏、学习状态和快速记录保存在浏览器 localStorage。当前不包含账号、云端数据库、多人协作和在线内容管理后台。
