# 信息架构

## 对外主导航

```text
首页
├── 项目
├── 文章
├── 工具
└── 关于
```

主导航保持精简，优先回答“做过什么、如何思考、沉淀了什么”。

## 扩展知识入口

```text
文章 / 知识入口
├── 术语
├── 阅读
└── 资料架

个人工具入口
├── 全局搜索
├── 已保存
├── 练习
└── 个人工作台
```

## 内容关系

内容实体通过稳定 ID 建立关联：术语帮助解释文章和项目，文章记录理解过程，项目提供实践证据，工具承接可复用方法。关联只保存 ID，不把其他实体的正文复制进当前对象。

主要 URL：

| 栏目 | 地址 |
| --- | --- |
| 首页 | `#/home` |
| 项目 | `#/work`、`#/work/:id` |
| 文章 | `#/notes`、`#/notes/:id` |
| 术语 | `#/topics`、`#/topics/:id` |
| 阅读 | `#/reading`、`#/reading/:id` |
| 工具 | `#/toolbox`、`#/toolbox/:id` |
| 资料 | `#/library` |
| 工作台 | `#/workspace` |
| 已保存 | `#/saved` |
| 关于 | `#/about` |
