## 项目保存方式

项目源代码、资源、测试和配置保留在仓库根目录的原有结构中；本目录保存当前任务的对话与交接说明，不在 docs 中重复嵌套整个项目。

## 当前已实现

- 首屏保留“把 AI 想明白，也把它做出来。”，定位标签为 AI PRODUCT / AGENT / BUILDING。
- 右侧展示 AI Learning OS，案例入口连接现有 personal-knowledge-lab 项目。
- 去除 CURRENTLY BUILDING 绿色标签，保留 BUILDING · 2026 状态。
- 首屏缩窄并增加边距，调整项目卡片、人物和方法卡片比例，适配移动端。
- 盆栽叶片通过局部 CSS 着色变绿，保留原始透明图片和互动坐标。
- 宠物每 5 秒触发与手动点击相同的表情、符号和提示语切换，卸载页面时清理定时器。
- 首页后续区域的网格减淡并疏化，能力内容面板使用不透明底色，避免网格干扰文字。

## 仍在讨论，尚未实施

- 第二屏的“自述 + 学习手记”曾提供独立 HTML 示例，未替换现有第二屏。
- “正在理解 / 正在尝试 / 正在留下”是学习过程表达，与文章、项目、工具的栏目入口存在语义差异。
- 最新建议为“简短自述 + 网站阅读入口”，但用户随后提出它可能与首屏的项目、文章按钮重复，也表达了可以结合的想法。
- 上述入口如何分工还未定稿。继续设计时，应先处理首屏与第二屏的信息重复，再实施第二屏。
- 第三屏及后续的项目、文章、方法展示仍属于规划。
