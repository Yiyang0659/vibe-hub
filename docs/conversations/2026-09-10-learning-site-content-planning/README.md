## 当前定位

“想与做”是一个记录 AI 学习与实践过程的个人网站。现阶段不依赖大量成熟项目和长文章，先持续积累术语理解、学习笔记、小实验、实践过程和可复用工具，再让这些记录逐渐形成专题、文章与项目案例。

## 本轮已经实现

1. 导航调整为“首页 / 项目 / 学习 / 工具 / 关于”，新增统一的学习入口，旧文章入口继续兼容。
2. 首页后续区块围绕最近学习、实践项目、工具方法和成长记录组织，同时保留已确认的首屏和第二屏风格。
3. 学习页聚合知识条目、笔记、成长记录和专题，支持搜索、分类、类型与专题筛选。
4. 项目、知识、笔记和工具采用可复用详情组件；内容增删主要通过数据文件完成。
5. 增加发布状态、链接安全与可选字段校验，草稿和待审内容不进入公开列表和搜索。
6. 写入首批真实内容：个人学习网站项目、两篇建站笔记、一条成长记录、一个专题、DeepSeek Harness Sync 和发布检查清单。
7. 补充内容填写指南、设计方案、实施记录与自动化测试。

## 最新讨论结论

用户在首期实现后再次梳理长期内容，提出“项目 / 知识 / 自己的沉淀 / 工具与收藏 / 关于”五类内容。当前建议将长期主导航进一步收敛为：

```text
首页 / 项目 / 知识 / 思考 / 资源 / 关于
```

这只是最新规划，尚未修改前端。分类以读者用途为主：

- 项目记录明确目标、实际行动、阶段、成果、问题和复盘，允许进行中或暂停的小实验。
- 知识解释可复用的概念、原理和方法，可以包含作者自己的理解与整理。
- 思考保存具体情境下的笔记、分析、判断与复盘，不要求每篇都是成熟长文。
- 资源收录工具、插件、Skill、Prompt、模板、网站和资料，并标注原创、外部或改编来源。
- 系列是一种跨内容组织关系，不单独复制正文，也不强制预先规划完整课程。

先逐条盘点现有数据，确定每条内容的主要归属和来源，再实现“知识 / 思考 / 资源”入口及旧路由兼容。不要仅按内容是不是自己写的、篇幅长短或是否开源来分类，也不要为了填满栏目虚构项目、成果或使用体验。
