# 已确认首页的基础规范

更新：2026-09-10。当前范围：首页前两屏与全站现有导航。项目、文章、工具的内容布局和详情模板尚未定稿，本规范不固定它们的展示形式。

## 权威来源与使用方式

`src/styles/home-foundations.css` 是当前已确认的首页尺寸与公共交互规则来源，由 `src/styles/index.css` 最后加载，统一覆盖旧首页布局中的局部尺寸。调整全站基础比例时修改此文件的 `--site-*` 变量，不在各栏目末尾再添加宽度或字号补丁。

`tokens.css` 保留已有字体、颜色、圆角变量。新规则复用这些变量，不改动旧内页模板。`home.css` 负责首页具体编排、插画、互动和装饰。后续迁移时可以逐步删除旧样式中被覆盖的尺寸，避免一次重写其他未定稿页面。

## 页面边界与高度

- 外层内容最大宽度：1216px，首页所有 `.zh-container` 共用，取消第二屏在大屏下单独扩大到 1400px。
- 桌面边距：`clamp(24px, 6vw, 96px)`；达到最大宽度后居中。
- 900px 及以下：边距 32px；760px 及以下：24px；380px 及以下：20px。
- 首页前两屏左右分栏间距：32–56px；900px 及以下转为上下布局。
- 普通分区上下内边距各64px（手机40px），两个普通分区之间合计128px（手机80px）。
- 首屏最小高度 `clamp(680px, 100svh, 860px)`；内容更多时仍可撑开，禁止固定高度裁切。桌面顶部116px、底部48px。
- 桌面高度不超过740px：首屏按内容撑开，上108px、下36px；平板和手机也按内容自然展开。
- 第二屏及后续不强制一屏高。允许文字与插画产生不同内容高度，边界和间距必须一致。
- 导航最大1024px，滚动后只改变顶部位置和外观，不改变宽度。手机导航保持距边12px，正文仍按24px；这是控制栏与阅读区的有意区分。

## 已确认组件和交互

- `.zh-button--primary`：深蓝主行动；`.zh-button--secondary`：白色实底次行动；按钮统一最小高度48px、字14px、水平内边距21px、胶囊圆角，主次组间距12px。
- `.zh-nav-links`：现有首页/项目/文章/工具/关于导航，最小点击高度44px；工具图标按钮44×44px。保留选中态、移动端菜单和原路由。
- `.zh-guide-row`：图标、标题、说明、箭头，整行链接；标题与说明稳定为上下结构，不在宽屏突然切换为另一种排版。
- 键盘聚焦：2px主题色轮廓，外扩3px。
- AI Learning OS 卡片不跳转；书桌铭牌纯展示。三张统计卡保持独立；人物互动、首屏内容顺序均保留。
- 颜色与主题沿用现有变量。本文不统一所有内页卡片、也不定义文章或项目的最终模板。

## 后续定制页面怎样继承

新页面外层使用 `.site-container`，分区可以使用 `.site-section`，标题与正文可用 `.site-section-title` / `.site-body`，按钮可用 `.site-button` 继承尺寸；配色与状态参考现有首页主次按钮，等栏目确认后再共享完整组件。按具体页面语义设置标题级别。

只有外层容器决定屏幕边距；嵌套模块不要再次套 `.site-container` 扣边距。组件自行决定内部排列，但优先引用 `--site-column-gap` 和 `--space-*`。需要新表现形式时可以新增组件，不能另建一套1216/1400等冲突宽度。

文章和项目的数据字段、详情结构、封面比例、正文阅读宽度以后单独确认。本次不冻结这些设计。
