# 四个栏目介绍首屏与主题图标

本次在当前开发分支增加知识、思考、资源、关于的介绍首屏。原有目录与内容继续保留在下方，首页和项目页结构保持现状。

## 页面结构

统一使用左侧标签、大标题、说明文字和一个向下浏览按钮；右侧为轻量展示面板、三个阅读步骤及两张说明卡。沿用全站容器、字号和颜色变量，保留浅网格、圆角与蓝绿点缀，不加入人物插画。

- 知识：查清概念 → 串起知识 → 回到实践；第二屏保留术语分类、系列与搜索。
- 思考：问题与观察 → 判断与尝试 → 复盘与修正；第二屏保留思考记录目录。
- 资源：明确用途 → 查看方法 → 带回实践；第二屏保留资源分类与搜索。
- 关于：理解问题 → 动手尝试 → 记录复盘；下方保留记录方式等个人介绍内容。

共享实现位于 `src/features/columns/intro.js` 和 `intro.css`。后续可在配置中调整文案，无需重复定义四套布局。桌面为双栏，手机自然堆叠，不强制固定高度。

## 交互

导航进入栏目先看到介绍；首屏按钮滚动至目录。显式搜索或分类链接可直接进入目录。从详情返回同一目录时保留筛选与阅读位置。修正知识详情返回入口被固定导航遮挡的问题。

亮色模式显示月亮；点击后进入暗色并显示太阳；再点击恢复亮色。图标、无障碍提示和持久化主题同步。
